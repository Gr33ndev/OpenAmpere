# SAJ type code 0x005E, "3P-X E2"

> Not official manufacturer information: compiled by the OpenAmpere contributors, can be incomplete or wrong. Changing
> inverter settings can affect the warranty and grid rules; no affiliation with SAJ or EKD; not legal advice. See the
> [device knowledge README](../README.md).

**Applies to:** SAJ inverters reporting type code 0x005E in register 0x8F00 · **Sold as:** "Ampere.StoragePro" (EKD) ·
**OpenAmpere:** driver `saj`, register map `saj_h2` · **Support:** display and control (since 0.29.0) · **Confirmed on
a real device:** partly (identification, live values and battery limits; in daily use by an owner, OpenAmpere's single writes not
checked one by one)

Everything this type shares with the H2/HS2 family (registers, behaviour, grid charging, export limit, decisions) is on
[h2-family.md](h2-family.md). This page holds only what is specific to 0x005E.

## Summary

- 0x005E is not in SAJ's H2 protocol, which lists 0x0055–0x005D. The name "3P-X E2" comes from the manufacturer's app
  of an owner.
- A three-phase type, sold by EKD as "Ampere.StoragePro".
- Read with the H2 map; detection, live values and the battery limits worked on a real device.
- Control is enabled because its settings registers matched the manufacturer's app
  ([#334](https://github.com/Gr33ndev/OpenAmpere/issues/334)).

## Decisions in OpenAmpere

| Decision | Why | Issue/PR |
|---|---|---|
| 0x005E is named "3P-X E2", without the power class; the rated power is read from 0x8F01. Without a class to check it against, the export limit waits for the owner's confirmation of the rated power ([#492](https://github.com/Gr33ndev/OpenAmpere/issues/492)). | One type code covers several power classes (0x005B covers 5 to 10 kW). | [#339](https://github.com/Gr33ndev/OpenAmpere/issues/339), [#379](https://github.com/Gr33ndev/OpenAmpere/issues/379), [#492](https://github.com/Gr33ndev/OpenAmpere/issues/492) |
| Control is enabled for 0x005E (battery settings, export limit, grid charging), as for the H2 and HS2. | Its settings registers matched the manufacturer's app. | [#334](https://github.com/Gr33ndev/OpenAmpere/issues/334), [#378](https://github.com/Gr33ndev/OpenAmpere/issues/378) |
| The summed grid counters are used when the device answers them, otherwise L1 (same rule as the family). | Three-phase: L1 alone would miss two phases. | [#379](https://github.com/Gr33ndev/OpenAmpere/issues/379) |
| A fault is notified only after it has lasted 30 minutes (all devices). | The nightly fault of this type sent a false alarm every morning; a real fault still lasts. | [#404](https://github.com/Gr33ndev/OpenAmpere/issues/404) |

## Open questions

- Whether a 0x005E answers the summed grid counters 0x4167 ff. on every firmware is not recorded.
- OpenAmpere's writes (battery settings, 0x3651, export limit, charge slot) are in daily use but not yet confirmed one
  by one on a 0x005E
  ([#378](https://github.com/Gr33ndev/OpenAmpere/issues/378)).
- What the nightly fault is (fault bit 23, about ten minutes in the early morning): the running mode 0x4004 and the
  three fault words during the event are not recorded yet
  ([#404](https://github.com/Gr33ndev/OpenAmpere/issues/404)).
- The open questions of the family apply as well: [h2-family.md](h2-family.md#open-questions).
