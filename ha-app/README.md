# OpenAmpere

Local app for solar systems with battery storage (FoxESS H3, SAJ H2/HS2): live values, history, battery settings and
grid charging, without a cloud. It talks Modbus TCP to the inverter in your home network.

It brings its Home Assistant integration along (sensors for the Energy dashboard and, if you allow it, control of the
battery): no HACS needed.

*Deutsch: Lokale App für Solaranlagen mit Batteriespeicher, ohne Cloud. Die Integration für Home Assistant bringt sie
mit, HACS brauchst du nicht. Die Anleitung steht im Reiter „Dokumentation“.*

OpenAmpere is an independent open-source project. It is not affiliated with Home Assistant, the Open Home Foundation
or Nabu Casa, nor with the manufacturers of the devices it supports.
