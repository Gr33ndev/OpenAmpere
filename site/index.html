Deine Solaranlage.
Lokal. Ohne Cloud.

OpenAmpere ist eine App für Solaranlagen mit Batteriespeicher. Sie spricht direkt im Heimnetz mit deinem Wechselrichter – ohne Konto, ohne Hersteller-Server, ohne Abo. Deine Daten bleiben bei dir.

Demo ausprobieren Auf GitHub ansehen

Die Demo läuft komplett in deinem Browser mit erfundenen Werten.

Für wen?

Unterstützte Geräte

  • FoxESS H3, H3 Smart, H3 Pro – Anzeige und Steuerung
  • SAJ H2 / HS2 – Anzeige
  • Heizstab, Wärmepumpe & Co. über Shelly-Relais

Das Gerät wird automatisch erkannt. Verbunden wird über Modbus TCP im Heimnetz.

Ohne Technikwissen

Ein Assistent sucht den Wechselrichter im Heimnetz, alles Weitere stellst du in der App ein. Läuft auf einem Raspberry Pi, einem NAS oder einem Heimserver – überall, wo Docker läuft.

Hattest du bisher eine Hersteller-App, die nur über die Cloud funktioniert? Hintergrund lesen

Funktionen

Live-Energiefluss

Solar, Haus, Speicher und Netz auf einen Blick – mit Ladestand und Richtung.

Report & Ersparnis

Tag, Woche, Monat, Jahr. Autarkie, Eigenverbrauch und was dir die Anlage spart.

Je Modulfeld

Ertrag von Süddach, Westdach oder Garage getrennt – dazu alle Temperaturen.

Speicher & Notstrom

Notstrom-Reserve, Ladegrenzen und Betriebsmodus – mit Testmodus und Protokoll.

Einspeisebegrenzung

Nach der Regel, die für deine Anlage gilt: 60 %, 70 % oder Wert vom Netzbetreiber.

Tarife & Laden nach Preis

Fest- und Börsenstrompreis. Speicher experimentell zur günstigsten Zeit laden.

Überschuss nutzen

Heizstab oder Wärmepumpe einschalten, wenn die Sonne mehr liefert als gebraucht wird.

Benachrichtigungen

Hinweise aufs Handy über ntfy: Störung, nicht erreichbar, Speicher voll.

Diagnose & Export

Gerät prüfen, ohne etwas zu ändern. Alle Werte als CSV für Excel.

So funktioniert es

Installation in drei Schritten

  1. Docker bereitstellen

    Auf einem Raspberry Pi, einem NAS oder einem Heimserver (z. B. Proxmox). Der Wechselrichter muss im Heimnetz erreichbar sein und Modbus TCP aktiviert haben – das erledigt im Zweifel der Installationsbetrieb.

  2. OpenAmpere starten

    git clone https://github.com/Gr33ndev/OpenAmpere.git openampere
cd openampere
docker compose up -d --build

  3. Im Browser einrichten

    http://<server-ip>:8080 öffnen, Passwort festlegen – der Assistent findet den Wechselrichter. Auf dem iPhone lässt sich die Seite wie eine App auf den Home-Bildschirm legen.

Ausführliche Anleitung, Betrieb hinter einem Modbus-Proxy und Zugriff von unterwegs: README auf GitHub.

Sicher von Anfang an

Steuern ist ab Werk aus

OpenAmpere liest zunächst nur. Wer Einstellungen ändern will, gibt die Steuerung ausdrücklich frei, testet im Testmodus und findet jede Änderung im Protokoll. Werte werden vor dem Schreiben geprüft und danach zurückgelesen.

Dein Netz, deine Daten

Ansehen im Heimnetz, Ändern nur mit Passwort. Keine Telemetrie, keine Werbung. Für unterwegs ein VPN (z. B. FRITZ!Box, WireGuard, Tailscale) – nie eine Portfreigabe ins Internet.

Mitmachen

Jede Anlage hilft: Teile einen Diagnosebericht deines Geräts, melde Fehler oder bring Ideen ein – auch ohne Programmierkenntnisse.
